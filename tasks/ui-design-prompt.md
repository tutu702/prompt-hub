# PromptHub UI 设计提示词

> **用途**：本文档作为给 AI 设计工具（Pencil、Figma Make、Stitch、Open Design 等）的输入提示词，用于批量生成 PromptHub 产品的 UI 设计稿。  
> **使用方式**：将本文档"设计提示词主体"章节整段复制，或按单页面拆分为多个会话输入。  
> **版本**：v1.0 配套 PRD v1.0（2026-09-21）

---

## 一、设计输入背景（AI 工具须遵循的产品上下文）

### 1.1 产品背景

**PromptHub** 是一个面向个人用户的 AI 提示词资产管理工具，目标用户为开发者、研究者、写作者、产品经理等高频使用大模型的人群。系统解决"提示词散落各处、难检索、难复用、难演进"的痛点，提供**集中存储、分类管理、AI 调优、版本对比**能力。Web 应用，PC 优先，响应式适配移动端。

### 1.2 核心使用场景

- 场景 A：用户在浏览器中快速打开网页，查看自己收藏的提示词并一键复制使用。
- 场景 B：用户粘贴一段提示词，让 AI 调优为更专业的版本。
- 场景 C：用户用自然语言描述需求，让 AI 自动生成一个可用提示词。
- 场景 D：用户在多供应商大模型（OpenAI / Anthropic / DeepSeek / 通义千问 / 智谱 / Moonshot / 自定义）之间管理 API Key 与连接。

### 1.3 设计基调

- **风格关键词**：专业克制、清晰高效、信息密度适中、留白舒适。
- **情绪**：让用户感觉"我的提示词井然有序、值得信赖"。
- **避免**：过度娱乐化插画、卡通化图标、儿童配色、营销弹窗。

### 3.6 图标规范

- **风格**：线性（Line）1.5px 描边，圆角端点，统一 24×24 网格；填充型仅用于已选中或激活态。
- **图标库建议**：Lucide / Tabler Icons / Phosphor（线性）。
- **必备图标**：搜索、筛选、复制、编辑、删除、收藏（星）、调优（魔法棒/魔杖）、AI（机器人/星花）、导出、导入、新建、关闭、眼睛（查看密码）、刷新、设置、用户、退出、提示、警告、成功、加载。
- 分类图标：可使用 emoji 或自定义线性小图标（如 `</>`、`✎`、`📚`），保持简洁。

### 3.7 通用交互规范

- **按钮**：主按钮（蓝底白字）、次按钮（白底蓝字蓝边框）、文字按钮、危险按钮（红底白字），禁用态统一 0.4 透明度。
- **输入框**：默认 1px `#E2E8F0`，hover 颜色加粗，focus 时 2px `#1677FF` 描边 + 4px `#E6F1FE` 光晕。必填项在 label 旁标 `*`。错误态红色描边 + 下方红色提示文案。
- **Toast**：右上角堆叠，3 秒自动消失，类型（success/info/warning/danger）用左侧 4px 色条 + 图标。
- **确认弹窗**：标题 + 内容 + 主/次按钮，危险操作主按钮使用红色。
- **加载**：按钮内联 spinner；列表使用骨架屏 6–10 行；全屏加载居中圆形 spinner + 文案"加载中…"。
- **空状态**：居中插画（线性几何或简单蓝色块）+ 主标题 + 副标题 + 1–2 个 CTA 按钮。
- **响应式断点**：`sm 640` / `md 768` / `lg 1024` / `xl 1280` / `2xl 1536`；PC 优先，移动端降级到 1 列堆叠。

## 五、组件要求（Component Library）

### 5.1 通用组件

- **Button**：主/次/文字/危险 4 类 + 3 种尺寸（SM/MD/LG）+ 加载态 + 图标位。
- **Input / Textarea / Password**：含前后缀插槽、字符计数、错误提示。
- **Select**：单/多选，可搜索、可清空。
- **Switch**：启用/停用切换。
- **Checkbox / Radio**：用于批量选择与单选。
- **Tag / Badge**：分类标签、状态徽标。
- **Modal / Drawer**：确认弹窗、表单弹窗、抽屉。
- **Toast**：顶部右角。
- **Pagination**：页码 + 跳转 + 每页条数。
- **EmptyState**：插画 + 标题 + 副标题 + CTA。
- **Skeleton**：列表/卡片骨架。
- **Avatar**：圆形 + 文字回退。
- **Divider / Card**：基础容器。

### 5.2 业务组件

- **PromptCard**（提示词卡片）：
  - 顶部：标题（截断 1 行） + 收藏星标（右上角）
  - 中部：描述（截断 2 行）
  - 底部：分类 Tag + 更新时间（相对时间，例"3 小时前"）+ 操作图标组（复制 / 编辑 / 调优 / 删除）
  - 鼠标悬停：阴影从 sm → md，操作图标淡入
  - 多选态：左上角显示复选框
- **ModelConfigCard**（模型配置卡片）：
  - 显示：别名、供应商（Tag）、模型名、启用开关、"设为默认"按钮
  - 状态徽标：已启用 / 已停用 / 默认
  - API Key：脱敏显示 `sk-***xxxx`
- **CategoryItem**：名称 + 颜色圆点 + 关联数量 + 上下移动 + 编辑 + 删除。
- **TunePanel**（调优左右分栏）：
  - 左栏：原始提示词标题 + 等宽字体内容 + 元信息
  - 右栏：调优结果（流式更新时有打字机光标）+ 操作按钮（保存为新版本 / 应用到当前 / 重新生成 / 复制）
  - 底部：调优诉求输入框 + 模型选择 + "开始调优"按钮
- **DiffView**（调优对比视图）：
  - 并排模式 + diff 高亮模式（绿增红删）
  - 顶部切换 Tab 控件

### 5.3 表单与状态约定

- **必填项**：label 后加 `*`；占位符示例：`"请输入邮箱地址"`。
- **错误提示**：输入框下方 12px 红色文字，图标 + 文本。
- **成功反馈**：Toast + 必要时的勾选动画。
- **危险操作**（删除、批量删除）：二次确认弹窗，按钮"确定删除"使用红色。
- **加载状态**：按钮置灰 + spinner；列表骨架屏；全屏加载遮罩。

### P04 提示词创建页 `/prompts/new`

**画布**：1440×≥900  
**布局**：左右两栏（左 280px 步骤导航 / 可选）+ 右主内容。

- 顶部 Tab 切换：[ 手动创建 ] [ AI 自动生成 ]，当前 Tab 有蓝色下边框。
- 模式 A（手动创建）：
  - 标题输入框（占位符"给这个提示词起一个名字，例如：代码评审助手"）+ 字符计数
  - 描述输入框（占位符"一句话说明这个提示词的用途"）
  - 分类下拉（带"+"新建分类）
  - 内容大文本域（高 400，等宽字体，行号可选）+ 字符计数
  - 标签输入（Tag 形式输入回车添加）
  - 底部：次按钮"取消" + 主按钮"保存并新建" + 主按钮"保存"
- 模式 B（AI 自动生成）：
  - 顶部"用途描述"大文本域（占位符"尽可能描述你想要 AI 生成什么样的提示词…"）+ 字符计数
  - 中部两列：风格（专业/友好/简洁/详细）、语言（中文/英文/自动）
  - 模型选择下拉（显示别名+供应商，例：`Max 的 GPT-4 · OpenAI`）
  - 主按钮"开始生成"
  - 生成中：右侧出现"生成中…"骨架 + 打字机光标
  - 生成完成：结果显示在大文本域，可编辑；下方 [重新生成] [应用到当前] 按钮
- 退出未保存提示：拦截 + 二次确认。
