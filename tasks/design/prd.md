## 一、项目概述

### 1.1 项目背景

随着大语言模型（LLM）在编程、写作、研究、办公等场景的广泛使用，个人用户积累的"提示词（Prompt）"越来越多。但目前这些提示词普遍散落在聊天记录、备忘录、文档、剪贴板等各处，存在以下痛点：

- **管理混乱**：提示词与对话内容混在一起，难以复用与检索。
- **质量参差**：同一需求的不同版本难以对比与择优。
- **切换成本高**：在不同 AI 平台之间搬运、改造提示词重复劳动。
- **无版本演进**：调优过程没有沉淀，难以回溯"为什么这个版本更好"。
- **缺乏分类与标签**：日积月累后无法形成结构化的个人知识资产。

**PromptHub** 旨在解决上述问题，为个人用户提供一个 **集中存储、分类管理、AI 调优、版本对比** 的私有提示词资产管理平台。

### 1.2 产品定位

- **目标用户**：个人用户（特别是开发者、研究者、写作者、产品经理等高频使用 LLM 的人群）。
- **产品形态**：Web 应用（PC 优先，响应式适配移动端），单用户系统（每个账户独立管理自己的提示词资产）。
- **核心价值**：把"散落的灵感文字"升级为"可检索、可演进、可对比、可复用的提示词资产"。

### 1.3 核心价值主张

| 维度 | 价值 |
| --- | --- |
| 集中化 | 所有提示词集中存储，一处管理 |
| 结构化 | 分类、收藏、搜索，让资产有序 |
| 智能化 | 内置 AI 生成、AI 调优，提升提示词质量 |
| 可演进 | 调优历史留痕，支持前后对比与版本回溯 |
| 可迁移 | 一键复制，一键批量导出，便于跨平台使用 |
| 可配置 | 灵活配置多家大模型供应商，按需启用 |

### 1.4 名词约定

- **提示词（Prompt）**：用户创建或调优的一段用于输入给大模型的指令文本，是系统的核心资产。
- **分类（Category）**：用户自定义的提示词分组（如"编程"、"写作"、"研究"）。
- **调优（Tune）**：由 AI 接管，对已有提示词按用户的要求进行改写、重写、增强。
- **调优历史（TuneHistory）**：调优前后对比的版本记录，用于回溯与择优。
- **大模型供应商（Provider）**：第三方 AI 服务（OpenAI、Anthropic、DeepSeek、通义、智谱、Moonshot 等 OpenAI 兼容接口或自建网关）。

## 二、用户角色与权限

### 2.1 角色清单

由于是个人工具，系统仅有一个角色：**已注册用户**。  
未注册访客可访问登录页、注册页，无权访问其他页面。

### 2.2 权限矩阵

| 功能模块 | 游客 | 已登录用户 |
| --- | --- | --- |
| 登录 / 注册 | ✅ 仅可访问登录注册页 | ❌ 已登录跳转首页 |
| 提示词列表 / 搜索 / 筛选 | ❌ | ✅ 仅本人数据 |
| 提示词创建 / 编辑 / 删除 | ❌ | ✅ 仅本人数据 |
| 提示词复制 / 收藏 / 导出 | ❌ | ✅ 仅本人数据 |
| 分类管理 | ❌ | ✅ 仅本人数据 |
| AI 调优 / 调优历史 | ❌ | ✅ |
| 大模型配置 | ❌ | ✅ |
| 个人设置 / 修改密码 | ❌ | ✅ |

### 2.3 数据隔离规则

- 所有业务表必须带 `user_id` 字段。
- 任何查询、新增、修改、删除操作均需要经过 `user_id` 过滤，禁止跨用户访问。
- 删除操作采用 **软删除**（保留可恢复能力），具体恢复策略见 §10。

## 五、详细页面与功能说明

### P01 登录页 `/login`

#### 字段

| 字段 | 类型 | 必填 | 校验规则 |
| --- | --- | --- | --- |
| 邮箱 | Email | 是 | 邮箱格式；不存在时统一提示"邮箱或密码错误"（防枚举） |
| 密码 | Password | 是 | 长度 8–64 |
| 记住我 | Boolean | 否 | 默认 false，仅影响 token 续期时长 |
| 登录按钮 | — | — | 校验通过后启用 |
| 注册入口 | Link | — | 跳转 `/register` |

#### 行为

- 登录成功后：写入 `access_token`（短期） + `refresh_token`（长期，HttpOnly Cookie），跳转 `/prompts`。
- 登录失败：统一提示"邮箱或密码错误"，不区分账号不存在/密码错误。
- 连续 5 次失败锁定 15 分钟（同一邮箱+IP），锁定期间返回 429。

#### 验收标准

- [ ] 输入合法邮箱+密码可登录成功并跳转。
- [ ] 输入错误密码显示统一错误提示，不暴露用户存在性。
- [ ] 空字段、格式错误、长度越界有实时校验。
- [ ] 未登录访问受保护页面自动跳转到 `/login?redirect=...`，登录后回跳原页面。

### P02 注册页 `/register`

#### 字段

| 字段 | 类型 | 必填 | 校验规则 |
| --- | --- | --- | --- |
| 邮箱 | Email | 是 | RFC 校验；唯一性校验 |
| 密码 | Password | 是 | 8–64 位；必须包含字母+数字 |
| 确认密码 | Password | 是 | 与密码一致 |
| 用户昵称 | String | 否 | 1–20 字符；默认取邮箱前缀 |
| 验证码 | String | 否（V1 可选） | 6 位数字，5 分钟有效 |
| 协议勾选 | Boolean | 是 | 必须勾选用户协议与隐私政策 |

#### 行为

- 注册成功后自动登录并跳转 `/prompts`。
- 邮箱已被注册：返回 409，提示"该邮箱已被注册"。
- 密码强度不通过：在密码输入框下方实时显示强度与原因（包含字母+数字）。

#### 验收标准

- [ ] 重复邮箱注册被拒绝并给出明确提示。
- [ ] 密码强度不足有实时提示。
- [ ] 注册成功后自动登录。
- [ ] 未勾选协议时注册按钮置灰。

### P03 提示词展示页（首页）`/prompts`

#### 顶部工具栏

- **搜索框**：实时搜索（防抖 300ms），匹配字段：标题、描述、内容（可切换"仅标题/全部"）。
- **筛选下拉**：
  - 收藏筛选：全部 / 仅收藏
  - 分类筛选：全部 + 用户自定义分类列表（按 sort 排序）
- **排序选择**（次级）：更新时间倒序（默认）/ 创建时间倒序 / 标题 A-Z
- **视图切换**：卡片视图（默认）/ 列表视图（V1 可仅卡片）
- **批量操作**：多选模式下显示【批量导出】【批量删除】操作
- **新建按钮**：跳转 `/prompts/new`
- **AI 生成入口**：跳转 `/prompts/new?mode=ai`

#### 提示词卡片字段

- 标题（截断 1 行）
- 描述（截断 2 行）
- 分类标签
- 收藏星标（可点击切换）
- 更新时间（相对时间）
- 操作图标区：复制 / 编辑 / 调优（AI）/ 删除 / 查看详情

#### 分页

- 每页 20 条，页码切换、跳转、上一页/下一页。
- 默认按更新时间倒序。

#### 空状态

- 无数据：插画 + 提示语 + 两个 CTA：【新建提示词】【AI 生成提示词】

#### 验收标准

- [ ] 分页加载、翻页、跳页正常。
- [ ] 搜索/筛选结果与查询条件一致，500ms 内反馈。
- [ ] 卡片上每个操作均可用，复制成功后 Toast 提示"已复制到剪贴板"。
- [ ] 删除前弹出确认弹窗"确定删除【XXX】吗？删除后可在 30 天内恢复"。
- [ ] 批量选择 + 批量导出可生成 zip 下载。
- [ ] 移动端响应式：卡片自适应 1/2/3 列。

### P04 提示词创建页 `/prompts/new`

提供两种创建模式（顶部 Tab 切换）：

#### 模式 A：手动创建

字段：

| 字段 | 类型 | 必填 | 校验 |
| --- | --- | --- | --- |
| 标题 | String | 是 | 1–100 字符 |
| 描述 | String | 否 | 0–200 字符 |
| 分类 | FK → Category | 否 | 只能选当前用户的分类 |
| 内容 | Text | 是 | 1–10000 字符；右下显示字符计数 |
| 标签 | Array<String> | 否 | 自定义标签，便于检索（V1） |

操作：
- **保存**：写入数据库，跳转详情页。
- **保存并新建**：保存后清空表单继续创建。
- **取消**：返回列表，提示未保存内容确认。

#### 模式 B：AI 自动生成

字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 用途描述 | Textarea | 是 | 用自然语言描述需求（如"帮我写一个 SQL 优化的提示词"） |
| 选择模型 | Dropdown | 是 | 从已启用的模型配置中选择 |
| 期望风格 | Dropdown | 否 | 专业 / 友好 / 简洁 / 详细 |
| 输出语言 | Dropdown | 否 | 中文 / 英文 / 自动 |

行为：
- 点击【AI 生成】调用大模型流式输出，生成完成后自动填入下方表单（可继续手动调整）。
- 生成失败显示明确错误提示并允许重试。

#### 验收标准

- [ ] 手动模式所有字段校验生效。
- [ ] AI 模式可调用已配置模型，生成结果可二次编辑、保存。
- [ ] 内容超出 10000 字符无法保存。
- [ ] 表单未保存时离开页面有二次确认。

### P05 提示词详情/编辑页 `/prompts/:id`

#### 视图

- 顶部：标题、描述、分类、内容（只读渲染 + 行号）。
- 中部：元信息（创建时间、更新时间、收藏状态、所属分类）。
- 底部操作区：
  - **复制**：复制全文到剪贴板。
  - **编辑**：切换为编辑模式。
  - **AI 调优**：跳转 `/prompts/:id/tune`。
  - **取消收藏 / 收藏**：切换星标。
  - **删除**：弹出确认。
  - **查看历史**：展开显示该提示词的调优历史时间线。
- **编辑模式**字段同创建页。

#### 调优历史展示

- 默认折叠，点击展开看到按时间倒序的列表，每行显示：版本号、调优时间、调优摘要（用户最初输入的诉求）、简要 diff（前后长度、首尾差异）。
- 点击某条历史进入 `/prompts/:id/tune?historyId=xxx` 查看完整对比页。

#### 验收标准

- [ ] 只读详情页与编辑页可清晰区分。
- [ ] 编辑保存成功提示并停留在详情页。
- [ ] 调优历史列表与详情对比页内容一致。
- [ ] 删除仅本人提示词可执行，他人 ID 返回 404。

### P06 提示词分类管理页 `/categories`

#### 功能

- 列表展示：分类名称、颜色、关联提示词数量、排序值、创建时间、更新时间。
- 顶部【新建分类】按钮。
- 行内操作：编辑、重命名、删除、上下移动（调整 sort）。

#### 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 名称 | String | 是 | 1–20 字符，同一用户下唯一 |
| 颜色 | String | 否 | HEX 颜色，用于卡片标签，默认灰 |

#### 删除约束

#### 验收标准

- [ ] 增、删、改、查闭环。
- [ ] 排序实时生效。
- [ ] 删除前有确认；存在关联提示词时给出阻断性提示。

### P07 提示词 AI 调优页 `/prompts/:id/tune`

#### 布局

- 左侧：原始提示词（只读）。
- 右侧：调优结果（生成中流式更新）。
- 底部：调优诉求输入区 + 操作按钮。

#### 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 调优诉求 | Textarea | 是 | 用户给 AI 的改写要求（如"让语气更专业、增加 few-shot 示例"） |
| 选择模型 | Dropdown | 是 | 已启用模型列表 |
| 上下文开关 | Boolean | 否 | 是否附加分类与描述作为上下文 |

#### 行为

1. 点击【开始调优】→ 调用大模型流式输出 → 同步渲染到右侧。
2. 调优完成后，【保存为新版本】将该版本写入调优历史（不覆盖原提示词）。
3. 【应用到当前提示词】会把原提示词覆盖（弹确认）。
4. 【重新生成】重新调用一次；可修改诉求后重生。
5. 【复制结果】复制调优后文本。

#### 调优历史记录字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 主键 |
| prompt_id | UUID | 关联提示词 |
| user_id | UUID | 所属用户 |
| version_no | Integer | 自增版本号 |
| request_text | Text | 用户的调优诉求 |
| original_content | Text | 调优前原文 |
| tuned_content | Text | 调优后文本 |
| model_config_id | UUID | 调优使用的模型配置 |
| created_at | Datetime | 创建时间 |

#### 对比视图

- 提供并排 / diff 高亮（绿/红）两种模式。
- 支持【将"调优后"设为当前内容】【丢弃】两个动作。

#### 验收标准

- [ ] 流式输出渲染无卡顿。
- [ ] 历史版本按 prompt_id 关联，列表可分页。
- [ ] 网络异常/超时给出降级方案（重试/取消）。
- [ ] 不替换原内容时一定有"保存为新版本"路径，不丢调优结果。

### P08 AI 大模型配置页 `/settings/llm`

#### 字段

| 字段 | 类型 | 必填 | 校验 |
| --- | --- | --- | --- |
| 名称（别名） | String | 是 | 1–20 字符，同一用户下唯一 |
| 供应商 | Enum | 是 | OpenAI / Anthropic / DeepSeek / 通义千问 / 智谱 / Moonshot / 自定义 |
| 模型名称 | String | 是 | 1–100 字符 |
| BaseURL | String | 是 | URL 格式（OpenAI 兼容接口基础地址） |
| API Key | Secret | 是 | 加密存储；前端显示时始终脱敏（如 `sk-***abc123`），允许查看完整值（需再次输入登录密码 / 二次确认） |
| 启用 | Boolean | 否 | 默认 true |
| 默认模型 | Boolean | 否 | 一个用户只能有一个默认，用于 AI 生成与调优缺省值 |

#### 列表视图

- 表格/卡片列表展示所有配置。
- 行内操作：设为默认、启用/停用、编辑、删除、测试连接。

#### 测试连接

- 触发后向后端发起一次最小调用（如 `chat.completions` 的 `max_tokens=1` 或官方轻量探测接口）。
- 返回结果：✅ 用时 132ms / ❌ 错误原因（超时 / 鉴权失败 / 模型不存在 / 余额不足）。

#### 安全要求

- API Key 仅在服务端解密后调用大模型，绝不下发到前端明文。
- 数据库存储采用对称加密，密钥从环境变量注入。
- 前端展示的"查看完整值"必须经过权限二次校验（确认密码或验证码）。

#### 验收标准

- [ ] 增、改、删、查生效，列表可正确显示启用状态。
- [ ] 默认模型唯一性保证（勾选新默认时自动取消旧的）。
- [ ] 测试连接能区分网络错误、鉴权错误、模型错误。
- [ ] API Key 列表展示始终脱敏，查看明文需二次确认。
- [ ] 至少需要一个启用配置才能使用 AI 生成/调优功能，否则给出引导。

## 六、业务流程

### 6.1 注册登录流程

```
游客 → /register → 校验邮箱唯一性/密码强度 → 创建用户 → 自动登录 → /prompts
游客 → /login → 校验凭据 → 颁发 token → /prompts
已登录 → 过期刷新 → 401 → 静默调用 refresh → 成功后重放原请求 / 失败 → 强制回 /login
```

### 6.2 提示词创建（手动）流程

```
/prompts/new → 表单填写 → 保存按钮
  → 校验字段 → 写入 prompts 表 (status=active)
  → 关联 category_id
  → 跳转详情页 → Toast 提示成功
```

### 6.3 提示词创建（AI）流程

```
/prompts/new?mode=ai → 用户输入需求 → 选择模型
  → 调用 /api/llm/chat (SSE 流式)
  → 流式输出实时显示生成结果
  → 用户点击【填入表单】→ 跳转手动模式并填充内容
  → 用户二次编辑 → 保存
  → 写入 prompts 表
```

### 6.4 AI 调优流程

```
/prompts/:id/tune → 加载原始内容 + 调优历史
  → 用户输入调优诉求 + 选择模型
  → 调用 /api/llm/tune (SSE)
  → 右侧流式更新
  → 用户确认结果
    ├─【保存为新版本】→ 写入 tune_history，不覆盖原 prompt
    ├─【应用到当前】→ 弹确认 → 覆盖原 prompt (修改 prompts.content) + 写入历史
    └─【复制结果】→ 仅复制
```

### 6.5 批量导出流程

```
/prompts 选择模式 → 多选 → 批量导出
  → 弹出导出格式选择（JSON / Markdown / TXT / 单文件多提示词 / zip 多文件）
  → 后端聚合 → 返回下载链接 / 文件流
  → 前端触发浏览器下载
```

### 6.6 模型配置测试流程

```
/settings/llm → 填写配置 → 点击【测试连接】
  → 后端用该配置发起一次最小请求
  → 返回 { ok, latency_ms, error_code, error_message }
  → 前端展示结果
```

### 6.7 修改密码流程

```
/settings/password → 输入当前密码 → 输入新密码 → 提交
  → 服务端校验当前密码 → 更新密码 → bump token_version
  → 使旧 refresh_token 全部失效
  → 强制回到登录页
```

## 九、非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 列表分页接口 P95 < 300ms；AI 流式首字 < 2s（取决于大模型） |
| 安全 | API Key 加密存储；密码 argon2；JWT 短期 + Refresh；二次校验查看敏感值；全站 HTTPS |

| 可观测性 | 服务端日志：关键路径埋点（登录、删除、导出、AI 调用）；前端埋点可选 |
| 数据备份 | 软删除保留 30 天可恢复，超过 30 天物理清理（异步任务） |
